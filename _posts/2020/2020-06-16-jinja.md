# NRE Labs - Using Jinja for Configuration Templates

## Part 1 - Introduction to Jinja

First, we need to install Jinja using `pip install jinja2`

Then we import the template module from Jinja.

```python
from jinja2 import Template
```

We'll use string variables to store our templates, files can be used too.
Let's pass a string variable into the `Template()` function to create our template object

```python
ipaddr_template = Template('{{interface}} has IP address {{ip_address}}')
```

With the help of the `template.render()` function, we can load the data in the template.

```python
interface_1 = ipaddr_template.render(interface='ge-0/0/0',
                                  ip_address='192.168.1.1')
print(str(interface_1))
```

- **Snippet :** Introduction to Jinja

    ```java
    from jinja2 import Template
    ipaddr_template = Template('{{interface}} has IP address {{ip_address}}')
    interface_1 = ipaddr_template.render(interface='ge-0/0/0',
                                      ip_address='192.168.1.1')
    print(str(interface_1))
    ```

    **Output :**

    ```
    ge-0/0/0 has IP address 192.168.1.1
    ge-0/0/1 has IP address 10.10.1.1
    fxp0 has IP address 172.16.1.1
    ```

- **Summary**
    - Jinja is a templating tool
    - Jinja templates are the text files that set the format of your output
    - `{{ }}` shows the template variables and can be loaded to the template using the `render()` function.
    - Jinja templates can be **reused** with a different set of variables.

## Part 2 - For Loops

Using `for` loops for variable assignment, `for` loops are very useful if you have your data in the form of a list/dictionary or the combination of both.

- **Snippet :** one-line templates using `Template()`.

    ```python
    from jinja2 import Template

    # Data

    interfaces = [{'interface': 'ge-0/0/0', 'ip_address': '192.168.1.1'},
                  {'interface': 'ge-0/0/1', 'ip_address': '10.10.1.1'},
                  {'interface': 'fxp0', 'ip_address': '172.16.1.1'}]

    # one-line template

    ipaddr_template = Template('{{interface}} has IP address {{ip_address}}')  # one-line template

    for element in interfaces:
    	interface_x = ipaddr_template.render(interface=element["interface"],
    								  ip_address=element["ip_address"])
    	print(str(interface_x))
    ```

    **Output :**

    ```
    ge-0/0/0 has IP address 192.168.1.1
    ge-0/0/1 has IP address 10.10.1.1
    fxp0 has IP address 172.16.1.1
    ```

- **Snippet :** multi-line tempaltes using `Environment()`.

    ```python
    from jinja2 import Environment

    # Data

    vlans = [{'vlan': 'VLAN10', 'vlan_id': 10},
             {'vlan': 'VLAN20', 'vlan_id': 20},
             {'vlan': 'VLAN30', 'vlan_id': 20}]

    # multi-line templates (Junos CLI configuration)

    env = Environment(trim_blocks=True, lstrip_blocks=True)

    vlan_config = env.from_string('''
    vlans {
    {% for item in vlans %}
        {{ item.vlan }} {
            vlan-id {{ item.vlan_id }};
            l3-interface irb.{{item.vlan_id}};
        }
    {% endfor %}
    }''')

    vlan_config = str(vlan_config.render(vlans=vlans))
    print(vlan_config)
    ```

    **Output :**

    ```
    vlans {
        VLAN10 {
            vlan-id 10;
            l3-interface irb.10;
        }
        VLAN20 {
            vlan-id 20;
            l3-interface irb.20;
        }
        VLAN30 {
            vlan-id 20;
            l3-interface irb.20;
        }
    }
    ```

    **Explanation :**

    - We are first declaring an instance of `Environment` called `env`. With this instantiation, we're passing two optional parameters. `trim_blocks` is used to trim an extra new line characters between consecutive iterations. `lstrip_block` strips the extra space/tab before a block.
    - The function `env.from_string` accepts a template in form of a string, which we're passing in directly as a string literal (no variable).
    - `{% for item in interfaces %}` begins our "for" loop. It specifies we want to iterate over each dictionary in the list `vlans`.
    - `{{ item.vlan }}` replaces the *template variable* `item.vlan` with the value for the *key* `vlan` .
    - `{{ item.vlan_id }}` replaces the *template variable* `item.vlan_id` with the item’s value for the key `vlan_id`.
    - Note that each starts with `item.`, which means we're accessing a value in the dictionary currently made available to us by our loop.
    - Since all of our fields are keys of the dictionaries within the list `vlans`, we only have to pass this in, and our template will access specific keys of each dictionary.

## Part 3 - "If" and "Set" Statements

In the snippet below: `set_template = '''{% set mgmt_interface = 'ge-0/0/0' %}` declares a variable `mgmt_interface` and sets its value to `ge-0/0/0`.

Then `{% if item.interface == mgmt_interface %}` checks if the item in the for loop has a key interface whose value is same as the value that we set for `mgmt_interface`.

If the value is same, it loads the template with the corresponding data, if not, it skips that element of list interfaces and moves on to the next.

```python
from jinja2 import Environment

interfaces = [{'interface': 'ge-0/0/0', 'ip_address': '192.168.1.1'},
              {'interface': 'ge-0/0/1', 'ip_address': '10.10.1.1'},
              {'interface': 'fxp0', 'ip_address': '172.16.1.1'}]

env = Environment(trim_blocks=True, lstrip_blocks=True)
set_template = '''{% set mgmt_interface = 'fxp0' %}
{% for item in interfaces %}
{% if item.interface == mgmt_interface %}
interfaces {
    {{ item.interface }} {
        unit 0 {
            family inet {
                address {{item.ip_address}};
            }
        }
    }
}
{% endif %}
{% endfor %}'''

int_template = env.from_string(set_template)
render = int_template.render(interfaces=interfaces)

print(str(render))
```
