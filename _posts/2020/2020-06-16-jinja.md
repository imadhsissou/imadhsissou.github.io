## Part 1 - Introduction to Jinja

First, we need to install Jinja using `pip install jinja2`

Then we import the template module from Jinja.

```python
from jinja2 import Template
```

We'll use string variables to store our templates, files can be used too.
Let's pass a string variable into the `Template()` function to create our template object

```python
ipaddr_template = Template('{{interface}} has IP address {{ip_address}}')
```

With the help of the `template.render()` function, we can load the data in the template.

```python
interface_1 = ipaddr_template.render(interface='ge-0/0/0',
                                  ip_address='192.168.1.1')
print(str(interface_1))
```

```python
from jinja2 import Template
ipaddr_template = Template('{{interface}} has IP address {{ip_address}}')
interface_1 = ipaddr_template.render(interface='ge-0/0/0',
                                  ip_address='192.168.1.1')
print(str(interface_1))
```

```
ge-0/0/0 has IP address 192.168.1.1
ge-0/0/1 has IP address 10.10.1.1
fxp0 has IP address 172.16.1.1
```

## Part 2 - For Loops

Using `for` loops for variable assignment, `for` loops are very useful if you have your data in the form of a list/dictionary or the combination of both.

```python
from jinja2 import Template

# Data

interfaces = [{'interface': 'ge-0/0/0', 'ip_address': '192.168.1.1'},
              {'interface': 'ge-0/0/1', 'ip_address': '10.10.1.1'},
              {'interface': 'fxp0', 'ip_address': '172.16.1.1'}]

# one-line template

ipaddr_template = Template('{{interface}} has IP address {{ip_address}}')  # one-line template

for element in interfaces:
	interface_x = ipaddr_template.render(interface=element["interface"],
								  ip_address=element["ip_address"])
	print(str(interface_x))
```

```
ge-0/0/0 has IP address 192.168.1.1
ge-0/0/1 has IP address 10.10.1.1
fxp0 has IP address 172.16.1.1
```

```python
from jinja2 import Environment

# Data

vlans = [{'vlan': 'VLAN10', 'vlan_id': 10},
         {'vlan': 'VLAN20', 'vlan_id': 20},
         {'vlan': 'VLAN30', 'vlan_id': 20}]

# multi-line templates (Junos CLI configuration)

env = Environment(trim_blocks=True, lstrip_blocks=True)

vlan_config = env.from_string('''
vlans {
{% for item in vlans %}
    {{ item.vlan }} {
        vlan-id {{ item.vlan_id }};
        l3-interface irb.{{item.vlan_id}};
    }
{% endfor %}
}''')

vlan_config = str(vlan_config.render(vlans=vlans))
print(vlan_config)
```

```
vlans {
    VLAN10 {
        vlan-id 10;
        l3-interface irb.10;
    }
    VLAN20 {
        vlan-id 20;
        l3-interface irb.20;
    }
    VLAN30 {
        vlan-id 20;
        l3-interface irb.20;
    }
}
```
